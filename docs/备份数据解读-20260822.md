## 1. LXY.JBR（竞赛作业文件，16 行）

```
P001 = 3,1,0,0,0,0,0, -268.166,56.1283,290.13, 3.10135,0.386687,-3.12376, 0
NOP
MOVJ P001 VJ = 10 % PL = 0 ACC = 10 DEC = 10 0
END
```

- 点位结构（14 元）按位置变量参数：**坐标类型 3,1 = 用户坐标系1**；左右手 0；运行手=0；
  XYZ=(-268.166, 56.128, 290.13) mm（**用户1 系**）；**ABC=弧度制存储**
  （3.10135 rad≈177.68°，0.386687 rad≈22.16°，-3.12376 rad≈-179.00°）；外部轴 0。
- 指令只有 1 条 MOVJ（10% 速、PL=0、ACC/DEC=10）。**目前没有任何 DOUT/WAIT 指令**——
  握手指令需新增（语法见 §6）。
- 结论：文件格式＝**任何坐标一律弧度存储**（与 isDeg 无关），这点与 0x2A03 的
  `pos=弧度 / posDeg=度` 完全一致。

## 5. isDeg=True ⇒ 7000 A/B/C 是"度"，代码必须按度转换

- `config.db → AppConfig.isDeg = 1`（示教器界面），`global.json isDeg=True` → **系统为角度制**。
- `.JBR`/0x2A03 `pos` = 弧度（存储制不变）；0x2A03 `posDeg` = 度；
  **7000 realPosPCS/UCS/ACS 的 A/B/C 随 isDeg 显示为度**（与示教器一致，用户确认）。
- ⚠️ `read_state()` 目前把 pose[3:6] 当弧度且**零转换** → 现在全链路姿态错 57.3× 旋转。
- 修法：`read_state` 增加 `angle_unit` 配置（当前=deg），A/B/C 度→弧度后再进
  `transform_from_inexbot_abc`；同时保持下发端（若走 0x3003/位置）用**弧度**。
- **回归校验锚点**（备份精确值，可用于离线/在线验证）：
  - 用户1原点（PCS 读数，基座系）：(578.2382, -79.7756, 301.5702) mm，
    A/B/C=(3.047881, -0.077894, -3.044496) rad ⇔ (174.63°, -4.46°, -174.43°)；
  - 机器人停在用户1零点时 7000 读数应等于上面（度显示下为 174.63/-4.46/-174.43）。

## 6. LXY 握手指令的官方语法（本地手册 18.6/15.2/15.6）

- 全局变量：GBxxx(布尔)/GIxxx(整数)/GDxxx(实数)，程序内可 `GI001=1` 或 `SET GI001`；
- **等待：`WAIT GI001 == 1 T=2 F=1 Return=GB001`**（T=超时秒，不填则死等；F=滤波）；
- **输出：`DOUT OGH#(DOUT)15 T=1 1`**（例：DOUT1-1 组，端口 15，T=时间，末尾=错误停止处理）；
- 读取组：`DIN IGH#(1)`（端口值存入 GI001）；`READ_DOUT GI001 OGH#(1)`；
- 运动等待：`WAIT_POS`（SPEED/POS + ACCURACY + MINTIME/MAXTIME）。
- 所以 PC↔LXY 双向握手**不需要 DIN 硬件**：
  - LXY→PC：`DOUT ...13 T=0 0`（状态位）＋ PC 读 0x3602/0x3603（已验证）或 Modbus 4x801；
  - PC→LXY：Modbus **4x501+0 (=GI001)** 写值 + LXY `WAIT GI001 == 1 ...`；
  - 气阀：指令 `DOUT OGH#(DOUT)15/16`，端口 15/16 与 0x3601 一致（(1,0)关 ∅(0,1)开）。

## 8. 现场验证优先级（按 30 分钟一组，全部本地可做）

1. **4x5=1 → 3x5 确认** → 读 **3x600** 作业名列表 → 记下 LXY 序号 N。
2. 作业选择：45=N **与** 45=N-1（0/1 索引）各测；**再测 41=N + 51=1**、49=N + 59=1；
   回读 3x41 与 3x49 与 **3x690**。
3. 开预约开关：示教器【设置→操作参数/远程设置】打开**预约运行使能**
   （对应 allowReserveRunningPro 与 remoteUseReserveModeFlag）→ 重走 61/71/29/19。
4. 若 19 仍不动：**4x121=1 单步**；**4x303=1 运动至当前点位**（先 301/302 选点）。
5. 变量通道：Modbus 写 4x501=1 → 读回 4x501 与(可选) 7000 numGVar 或 0x5608；
   若通 → LXY 用 `WAIT GI001 == 1` 作 PC 握手（竞赛方案闭环）。
6. DOUT：**4x900=1** → 写 4x801+14/15 → 0x3602 回读核对（对比 0x3601 的可靠性）。
7. 报错自动读取：写 4x140=1 清错 → 任何操作后读 **3x1000** 前若干寄存器。
8. 单位：0x2A02 一条查询读 pos/posDeg，与 7000 对照，确认 7000=度后改代码。
