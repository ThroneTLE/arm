# 机器人远程运行故障诊断记录（2026-08-22 晚）

> 目标：上位机（PC）远程运行作业文件 LXY。
> 结论：**除"程序启停/作业选择"外，远程通道全部打通**；该组寄存器在本固件为死功能，
> 需摩卡/纳博特确认，或采用备选方案（见文末）。

## 一、已验证通过的通道（全部实测）

| 功能 | 命令 | 实测结果 |
|---|---|---|
| 伺服上电（关键！） | 6001 `0x2311 {"robot":1}` | ✅ 回帧 `0x2003 status:3`（运行）——**这是正式使能通道**；`0x2301 deadman` 恒回 `deadman:0`（示教器按键通道，无关） |
| 伺服状态 | `0x2002 {"robot":1}` | ✅ `0x2003 status:0停止/1就绪/2错误/3运行` |
| 操作模式 | `0x2101 {"mode":1/2}` → `0x2102` | ✅ mode:1 远程 / 2 运行；切运行模式自动上电（runModeAutoManBegFlag=true） |
| 用户坐标号 | `0x3C0B {"robot":1}` | ✅ `0x3C0C curUserNum=1`（用户1 激活） |
| 夹爪 | 6001 `0x3601 {"port":15/16,"status":0/1}` | ✅ 气阀已验证 |
| 位姿回读 | 7000 `0x9512 realPosUCS/PCS/ACS` | ✅ 用户1系 (X,Y,Z,A,B,C)，**A/B/C 为度**（此前 ×57.3 为误读：ACS 就是度） |
| 复位点判定 | Modbus 3x 101 | ✅ =1（逐轴偏差 <0.03° < ±1°） |
| Modbus 会话 | 502 从站，持续 100ms 轮询 | ✅ 示教器显示【已连接】；`0x5718 ModbusConnect=true`；enable=true、stoprun=false、scancycle=100 |

## 二、打不通的死结（本固件未实现）

`configFile-21.05.23-4.1.1/configFile*/modbusAddr.json`（U 盘导出的**本机真实地址表**）确认存在：

- 4x 45 作业文件编号（直接更改）/ 61 运行次数 / 71 确认 / 29 伺服控制 / 19 程序启停 / 120 上使能
- 3x 49 当前作业编号 / 59 程序运行状态 / 690 当前作业名 / 120 使能状态

**实测（地址基准 = 手册值-1，即 1-based；3x 29/101/61 等读回值全部验证正确）**：

- 写 45=1（FC6 与 FC16 均试）→ `3x49` 恒 0、`3x690` 恒空 → **作业从未被选中**
- 写 19=1 / 19=3（脉冲、FC16、示教/远程/运行三种模式）→ `3x59` 恒 0、0x3D03 status 恒 0、机器人不动
- 写 120=1 → `3x120` 恒 0（但 `0x2311` 能上电，说明 120 是死寄存器、2311 是活命令）
- 示教器自己按【运行/启动】也无反应（"当前运行程序无"）→ **不是上位机问题，是控制器侧状态机**
- 单步运行（示教器/程序页单步）✅ 可执行 LXY（机器人动）

**判据**：程序启停/作业选择寄存器（45/19/120/121…）在 21.05.23-4.1.1 固件中为
"地址表存在、执行层未接入"（写全被静默丢弃，无任何回读变化）；0x45xx MOVJ/MOVL 亦
不支持（参数错误），0x2401 无回帧，0x2F1B 队列查询正常（队列=[LXY×1]）。

## 三、给摩卡的技术问题（可直接念/发）

> 设备：MR07S-930 六轴（7kg/930mm）+ 纳博特 C1102 控制器，固件 configFile 版本
> 21.05.23-4.1.1，Modbus 从站（TCP 502，已连接，enable=true，扫描 100ms）。
>
> 现象：上位机按《IO_Modbus与远程功能手册》6.5.5 流程——4x 45=1 选作业、61/71=1
> 运行次数、29=1 伺服就绪、19=1 运行作业文件——全部写入成功（FC6/FC16 均试），
> 但 3x49 当前作业编号恒 0、3x59 程序状态恒 0、机器人不动；示教器远程模式界面
> 自己的【运行】键同样无反应（当前运行程序无）。0x2311 {"robot":1} 可正常上电
> （0x2003 status=3），0x2F1B 预约队列显示 [LXY×1] 正常。

> 问题：1) 该版本"程序启停/作业选择"Modbus 寄存器是否为未实现功能？2) 若要远程

> 远程IO功能绑定、运行次数、开始DIN 等必须项清单）？3) 是否有该版本的

## 四、备选方案（竞赛可用，零风险）

1. **上电/停靠由 PC 负责**：`0x2311 {"robot":1}` 上电（已验证）；急停 `0x2314`；
   复位/回零（0x3007 GO_RESET_POSITION，验证通过）；
2. **夹爪**：0x3601 DOUT15/16（已验证）；
3. **位姿/视觉闭环**：7000 realPosUCS（已验证）+ 手眼矩阵（已标定）；
4. **程序运行唯一手动一步**：示教器【运行/启动】（单步+全跑均已验证可行）；
5. **作业文件内配合**：让 LXY 与上位机用 DIN/DOUT 握手（如 WAIT 指令 + DOUT 输出
   状态位），把"起始/完成"信号化——即使运行键手动按，抓取节奏仍全自动。
