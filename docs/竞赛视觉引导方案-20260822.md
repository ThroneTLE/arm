## 已验证链路（每项都有现场回帧证据）

| 环节 | 手段 | 证据 |
|---|---|---|
| PC→控制器 数值变量 | Modbus 4x 601 = GD001（Float **CD AB** 字节序，双 32bit/变量） | 写 123.456 → 回读解码 123.456 ✓ |
| 控制器→示教器 位姿 | `0x2A02 {"robot":1,"coord":3}` → `0x2A03 pos(弧度)/posDeg(度)/configuration` | configuration=8、pos 与示教器一致 ✓ |
| 伺服上电 | `0x2311 {"robot":1}`（0x2301 deadman 通道在本固件为死） | status 1→3 ✓ |
| 操作模式 | `0x2101 {"mode":0/1/2}`（0=示教/1=远程/2=运行，2 自动上电） | 0x2103 ✓ |
| 夹爪 | `0x3601 {"port":15/16,"status":0/1}` | DOUT15/16=(1,0)关/(0,1)开 ✓ |
| 复位点/安全点 | 3x101 回读=1（±1°/轴，当前偏差 <0.03°）；`0x3007` 复位 | ✓ |
| 作业运行 | 示教器【单步/试运行】= 唯一人工一步 | 用户实测 LXY 单步移机 ✓ |

## 作业文件模板 LXY（示教器【工程】粘贴）

```
//DIR
//JOB
//NAME LXY
//POS
P1001 = 3,1,0,0,0,0,0,-268.166,56.1283,290.13,3.10135,0.386687,-3.12376,0
//INSTRUCTION
NOP
POSSET P1001 UF 1 GD001
POSSET P1001 UF 2 GD002
POSSET P1001 UF 3 GD003
POSSET P1001 UF 4 GD004
POSSET P1001 UF 5 GD005
POSSET P1001 UF 6 GD006
MOVL P1001 V=100 mm/s PL=0 ACC=10 DEC=10 0
DOUT OT#(15)1
WAIT 1 1
DOUT OT#(15)0
DOUT OT#(16)1
END
```

- `UF` = 用户坐标 1；轴 1/2/3=X/Y/Z(mm)，4/5/6=A/B/C(**弧度**，与回读一致)；
- GD001..GD006 即 PC 写的 4x 601..612（Float CD AB）；
- DOUT/WAIT 按你示教器里夹爪实测的行写法替换即可（15=关/16=开 已验证）。

## 竞赛操作序列（每轮）

1. 视觉/手眼算得 用户1 系目标位姿（pipeline 已有手眼矩阵 + realPosUCS 回读）；
2. `write_gd_pose.py` 写 GD001..GD006（视觉得分）；
3. 示教器【单步/试运行】一次性执行（人工一键，其余全自动）；
4. `0x2A02` 回读 pos 与 GD 对比 = 精度闭环验证。

## 死结论（不要再试）

- `0x4501/0x4502`（MOVJ/MOVL JSON）本固件不支持：手册原样示例也报参数错误；
- Modbus 4x 45/19/120/121（作业选择/运行/上电/单步）写全被静默丢弃；
- `0x3114`（打开作业文件）会**导致控制器通讯服务崩溃**，严禁再发；
- `0x50A1/0x2401/0x2C01` 设置类命令无回帧（未实现）。
